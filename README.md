### ⭐ WebCond
Plataforma web para gestão condominial, com áreas para administração da plataforma, síndico e morador: unidades, importação por planilha, autocadastro por link, cobranças com fatura em PDF, avisos, documentos, ocorrências, suporte por chat, notificações push e instalação como app (PWA). Meu maior projeto até hoje.

- **Tecnologias:** React, Vite, JavaScript, Supabase (PostgreSQL, Auth, Storage, RLS), SQL, funções serverless Node.js, Vercel
- **Organização:** TSCBr
